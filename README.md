🚀 Projetos em Destaque

[AI Job Hunter](https://github.com/joaovtobias/ai-job-hunter)

Agente Autônomo de Triagem e Analytics
Um pipeline de ponta a ponta (ETL) que coleta vagas de estágio em portais corporativos, utiliza o modelo Gemini 3.0 Flash para ler dados não estruturados, gerar um Match Score com base no meu perfil e salvar tudo em um banco de dados SQLite. Conta com um dashboard interativo em Streamlit (Pandas) e automação de alertas via WhatsApp.

[AI Career Threat Analysis](https://github.com/joaovtobias/ai-career-threat)

Análise do Dataset sobre Ameaça de Automação em diferentes Cargos
Este projeto realiza uma análise exploratória de dados sobre o impacto e o risco de automação por Inteligência Artificial em diversas carreiras. O objetivo foi extrair insights sobre quais áreas estão mais vulneráveis, as tendências salariais e como a maturidade das ferramentas de IA afeta a adoção no mercado.
